# Página pública do Compensa

Pacote independente, sem dependências, credenciais, scripts ou acesso ao Supabase.

Publicar em um novo repositório `compensa-apresentacao`, separado do aplicativo.
Enviar SOMENTE `index.html`, `.nojekyll` e este README dessa pasta. Nunca enviar a
pasta ComprarBem, arquivos de ambiente, backups ou código do aplicativo.

No GitHub: Settings > Pages > Deploy from a branch > main > /(root).
A URL será https://USUARIO.github.io/compensa-apresentacao/; substitua USUARIO pelo
nome real do GitHub. Só informe essa URL à Awin depois de publicar e abrir o endereço
em uma janela anônima. A página não garante aprovação pela rede ou pelos anunciantes.

Não adicionar domínio próprio ou ferramentas pagas. GitHub Free exige repositório
público para Pages; o repositório conterá apenas estes arquivos de apresentação.
